REKVIZITOR 2.1 — исправленная мобильная версия.

Исправления: вертикальная компоновка, удаление фотографий ракурсов вместе с точками, круглые маркеры без надписей, поиск по комнатам и папкам, управление без свайпов и перетаскивания.

ВАЖНО: удаление ракурса удаляет только фотографию и её точки, но не полки и предметы.

Хранилище IndexedDB rekvizitor-v2-isolated сохранено для совместимости с 2.0 при использовании ТОГО ЖЕ origin/адреса сайта. Если изменить адрес сайта, локальная база автоматически не переедет: сначала экспортируйте JSON из старой версии, затем импортируйте в новую.

Для офлайн PWA разместите файлы на HTTPS, откройте в Chrome, установите приложение. Резервное копирование: Настройки → Экспорт.
